01 計測の自動化
今 週 中

原則:個別判断はしない。仕組みで取る。 誰が・いつ・どこから来たかは、運営の感覚や DMヒアリングではなく、設置した仕組みが拾う。

  • GA4 を index.html に追加
    • 訪問者・流入元・直帰率を自動取得
  • 全チャネルのリンクを UTM付き ハブURL に統一
    • X固定ツイート / Ameblo フッター / Coconala 説明欄 / YouTube 概要欄 / LINE OC ノート / LINE公式あいさつ
  • Google Form(1問アンケート)を 3箇所に常設
    • Q:どこでこのオプチャ/ブランドを知りましたか?
    • OC ノート固定 / LINE公式あいさつ / ハブフッター
    • GA4 の行動データに、意図データを補強
  • 1ヶ月放置 → データが溜まる
1ヶ月後、GA4 + Form で流入元の上位2チャネルが特定できる

02 最初の1人に届ける
今 月 中

Coconala 1年売上0 を抜ける唯一の方法は、不特定多数に発信を増やすことじゃなく、特定の1人に深く向き合うこと。広く待つんじゃなく、絞って取りに行く。

  • 接点のある人を10人特定
    • OC で2回以上「おはよう」を共有した人
    • Ameblo に反応してくれた人
    • X で言及してくれた人
  • 個別メッセージで関係構築(まず売り込まない)
    • 「LINE公式の配信、参考になってますか?」
  • 反応が良い人にだけモニター提案
    • 「21日プログラムのモニターを3人だけ募集してます。フィードバックいただける方は ¥1,000 で」
  • 最初の1人 に体験してもらう(無料でもいい)
  • 完了後「お客様の声」を許可付きで取得
体験者 1〜2人 + 声 2本 → Coconala 説明欄に反映
03 届く仕組みを作る
今 後 3 ヶ 月

ハブの価値化(7日コラム)

ハブを「リンク集」から「読み物」へ進化させる。訪問者が3秒で離脱しないために、即座に価値を渡せる構造に。

  • Day 1:体内時計の話
  • Day 2:二度寝との付き合い方
  • Day 3:朝活の罠(完璧主義)
  • Day 4:朝散歩の効果
  • Day 5:「目的」を持つ
  • Day 6:続ける仕組み
  • Day 7:ここから先(LINE公式への自然な誘導)
無料7日読み物(ハブ)→ 無料21日 LINE配信 → ¥3,000 Coconala 21日伴走 の動線完成

X 再構築(最大の課題)

86投稿 / 0フォロワーは「やってる方向が間違ってる」サイン。

  • 毎日 1投稿 + 5リプライ(早起き/朝活/自己管理 界隈)
  • リプライは「営業」じゃなく 会話 。短く、共感、自分の経験を添える
  • フォロー返し狙わず、価値あるリプを蓄積
  • 関連アカウント30人をリスト化、毎日見る
3ヶ月後 100フォロワー

LINE → X 連動運用

LINE配信のコンテンツを X にも展開し、毎日投稿の労力をゼロにする。

  • LINE配信 → 同内容を 140-200字に圧縮 → ハッシュタグ #早起き #朝活 を追加
  • Xアプリの予約投稿機能で仕込む(無料・¥0)
  • 21日分のスレッド連載化 → ハブへの導線にする
  • 1〜2週間運用後、続ける価値があれば X API完全自動化(C案)へ移行
LINE 21日daily配信に切り替える場合は、LINE 21本 → X 21本 がそのまま使える(コンテンツ作成1回で2チャネル分)。

Antigravity launch readiness

本命の収益源。

  • ベータユーザー 5〜10人を OC・X から募集
  • 体験 → フィードバック → 改善 のサイクル
3ヶ月後 ベータ 5人 / サブスク移行 2〜3人

コンテンツ継続(無理しない)

  • 値下げで集客(¥3,000は妥当)
  • 完璧主義(70%で出して反応を見る)
