設計

Claude / この画面

テーマと大枠ストーリーを決める（例：睡眠の質 → 起床習慣 → ゆるい朝活 → 習慣化）。

キャラ・環境リファレンスの仕様、カット割り（5〜15秒単位）を組む。

各カットのモーションプロンプト清書＋投稿テキスト＋ナレーション文を用意する。

★ ポイント

ここはクレジット消費ゼロ。手が空いている時に、何本でも先に作り溜めできる。動ける時のための仕込みはここでやる。

1

画像生成

TapNow / Midjourney V7

各カットの「1フレーム目＝シード画像」を作る。完成画がある場合はそれをそのまま使う。

★ 注意
  • 完成フレームがある時は白黒絵コンテ不要。そのまま i2v のシードでOK（絵コンテはゼロから構図を組む時のスタイル流出防止用）。
  • 画づくりの整合に注意。例：室内に落ち葉はNG → 埃／光の粒子に置き換える。
2

動画化

★ 要 Dreamina / Seedance 2.0

シード画像＋モーションプロンプトを渡して、i2v で5秒生成する。ここが一番崩れやすく、一番効く。

★ 効くレバー・崩れ対策
  • 「動きの強さ／Motion」スライダーを上げる。i2v は既定で保守的なので、これが一番効くレバー。
  • プロンプトは動き優先で書く（弱い動きを禁止する書き方）。「静か／超スロー」と書くと全く動かない。
  • 立つ・歩く・正面まで振り向く等の大きな全身アクションは i2v で崩れる → 開始／終了ポーズ指定の「新規生成」に回す。
  • 最終フレームを必ず保存 → 次カットのシードにする。だから“終わり方”を先に設計しておく。

クレジット：1本 ≈ 145。毎日225にリセット（繰越なし＝実質1日1本）。

3

音声

ElevenLabs

ナレーション文を音声化する。

★ 注意
  • 日本語は漢字 → ひらがな／カタカナにすると自然になる。
  • キャラに喋らせる音声リファレンスは「生麦生米生卵」等の無意味語で作る（実セリフを入れると声がそれに引っ張られる）。

無料プランは月10分（10秒ナレーションなら約60本分）。

4

合成

Claude チャット / Cowork

動画（複数カット）＋音声をアップ → ffmpeg で結合する。BGMなしで作ってあるので、繋ぎ目が自然になる。

★ 注意

生成時に「BGMなし」を必ず効かせる。ただし環境音・呼吸まで消えないよう “music only” で指定する。

5

投稿

X / Threads・手動

完成mp4＋投稿テキストを手動投稿する（動画投稿は手動）。投稿後にセルフリプライを追加する。

★ 注意
  • 1日1投稿を守る（連投は沈む）。
  • 予約はメイン投稿のみ（スレッド予約はX仕様上不可）。まとめて予約したい時だけ Claude in Chrome で一括。
  • 投資の断定的な金額投稿は避ける（投資助言リスク／ブランド方針）。
✓

通しで効くルール

忘れやすい順。

  • 単位は15秒が基本（一貫性を保ちきれる長さ）。今回は5秒×繋ぎで実験中。
  • 各カットは完全静止で終えない（余韻を残す＝次カットで自然に動き出す）。
  • 動画参照は使わず、環境リファレンスで位置を固定する。
  • 実写よりアニメの方が崩れやすい前提。動きは強く → 崩れたら削る、の順で詰める。
