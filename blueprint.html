ブランド・ブループリント

戦略の再構成 / 2026.05.25

朝活は「症状の入口」、本丸は「惑わされず人生の目的に向かう力」。

早起きは身体の土台のひとつにすぎず、ブランドの真の中心は 注意力 + 感情コントロール。 この再構成によって、提供価値・ペルソナ・カリキュラム・流入戦略の全部が組み直される。

01

ブランドの再定義

REDEFINITION

ブランドのコア定義

朝陽 黎 = 「画面の外で、自分に戻る場」

ミッション

惑わされず、人生の目的に向かって進むための土台を育てる

余計なニュース、SNSの喧騒、誰かの正解に振り回されず、自分の足で歩く。そのための注意力と感情の安定を、小さな日々の実践で育てる場。

土台の3層

LAYER 01
身体の土台
睡眠・起床・エネルギー管理。21日早起きプログラム(Coconala / LINE step messaging)が完成品としてここをカバー。
LAYER 02 — NEW CORE
注意力の土台
受動消費(動画・SNS・ニュース)を、能動アウトプット(書く・観察・連絡)に置き換える。「画面の外で、自分に戻る」がここに該当する新コア領域。
LAYER 03
感情の土台
思考と感情の観察、書いて手放す、ポジティブを保管する。注意力の土台と接続して、感情に振り回されない自分を作る。
直結 ブランドミッション「努力する人が報われる社会を」と直接つながる。努力するには、集中力と感情の安定が必要だから。

ペルソナとオーディエンス

WHO IT REACHES

3つのコアペルソナ

ペルソナ中の痛み朝陽 黎が刺さる点
ネガティブな人反芻、自己否定が止まらない紙に書いて捨てる(Briñol)
自己犠牲な人他者優先で休めない5分でいい、ゆるく続ける
モヤモヤしてる人言語化できない不安書き出して観察する

隣接ペルソナ(+3)

  • HSP・繊細な人 — 情報・人混みで疲れる(「画面の外」angle)
  • 完璧主義者 — 「ちゃんと」しないと気が済まない(「ゆるく」angle)
  • 共感疲労中の人 — 育児、介護、対人職(「自分に戻る」が直球)

朝活との関係 — 乖離は橋を架ける場所

朝活参加者の動機管理者の動機
方向押し出される(問題回避)引っ張られる(夢に向かう)
温度問題解決モード自己実現モード
時間軸今すぐ何とかしたい長期で育てたい

この乖離は問題じゃなく、橋を架ける場所。ライティング(自分に戻る時間)が、問題ベースの人と目的ベースの人の両方に効く:

  • 問題ベース → 紙に書いて捨てる → ネガが減る → 余白ができる
  • 目的ベース → 書いて残す → ポジが増える → 動き出せる

入口は違うけど、「書く」という同じ行為で接続できる。朝活で繋がった人が、自然に自分に戻る時間へ進める導線になる。

ストーリー 「自分は 夢を叶えるため に朝活を始めた。でも来てくれた人の多くは 眠れない・起きれない という困りごとを持ってた。その乖離に気づいて、両方をつなぐ場を作ってます」— blog / Coconala のオリジナル素材になる。
04

ライティング — 10モード + 3問フレーム

THE CORE METHOD

3問フレーム — 教え方の基本構造

ライティングを教える時、毎回この3問で構造化する。読み手が安心して読める。学ぶ側も選択できる。

  • 何を書くのか — 内容・トピック
  • なぜ書くのか — 目的・効果(エビデンス含む)
  • どのように書くのか — 方法・プロセス

10種類の書くモード

モード目的(なぜ)こんな状態の時
書き出し(brain dump)頭の中を空にする思考ぐるぐる、寝つけない
モヤモヤを捨てるネガを物理的に手放す(Briñol)反芻が止まらない
感情ジャーナル感情に名前をつける何が嫌か分からない
思考整理(仕分け)動かせる範囲を見る心配・不安が広がる
感謝ジャーナルポジに目を向ける燃え尽き、ネガティブ寄り
Done listできたことを見る完璧主義、自己効力感低下
価値観ライティング大事なものを言語化迷ってる、転機
未来日記方向を見る夢に向かいたい時
夜の振り返り一日を閉じる寝る前ぐるぐる
朝のひと言今日の意図を決める忙しい朝、シンプル派

ペルソナ × モード の対応

  • ネガティブな人 → 書き出し、捨てる、感謝
  • 自己犠牲な人 → Done list、価値観、感情ジャーナル
  • モヤモヤな人 → 感情ジャーナル、思考整理、書き出し

入口の多様性 = 流入の多様性。全員にどこかしら刺さるモードがある。

3問フレーム実例

モヤモヤを捨てる(Briñol)

何をネガティブな思考、ぐるぐる回ってる感情
なぜ物理的に手放すと心理的影響が弱まる(Briñol 2012)
どのように紙に書く → 破る or 捨てる(動作とセット)

感謝ジャーナル

何を今日感謝することを3つ(具体的に)
なぜポジティブ注意を育てる、ネガ優位を打ち消す
どのように寝る前に3つ。人・経験・物を混ぜる
差別化 ジャーナリング系の本やアプリの多くは「これをやって」と一方向。朝陽 黎は 「状態に応じて使い分ける」meta-skill を教える 設計にできる。
05

コミュニティ設計

COMMUNITY DESIGN

非対称設計 — ネガは捨て、ポジは保管する

Briñol 2012 の論文タイトル正式版:「Treating Thoughts as Material Objects Can Increase or Decrease Their Impact」

行為効果
ネガティブ思考を 捨てる影響が弱まる(=楽になる)
ポジティブ思考を 保管する(ポケット等)影響が 強まる(=効果が持続)
ポジティブ思考を捨てる影響が弱まる(=逆効果)

ネガティブは手放す、ポジティブは持っておく。これが鉄則。

ブランドの2つの動線

種類何をする場所
ネガティブ・モヤモヤ紙に書いて捨てる私的(密室)
ポジティブ・気づき・アウトプット書いて残す・共有するOC・ノート・blog

これにより、OC自体が「ポジティブの保管庫」として機能する。メンバーが過去ログを読み返せる → ポジティブが繰り返し効く。

OC 共有テンプレ

  • 今日のメモ(書いたことから1行) — 例:「焦らない。やりたいことから手をつける」
  • 今日のスワップ(受動 → 能動の置き換え) — 例:「夜のSNS → ストレッチ。肩が軽い」
  • 今日の気づき(小さな観察) — 例:「コーヒー、いつもより濃く感じた」

「おはよう」みたいに最低バー1語でOK。「今日のメモ(任意で内容)」のように空欄でも投稿可にすると「ゆるく」を保てる。

ポジ:ネガ比率の設計

  • 「今日のメモ」「スワップ」「気づき」 — 毎日OK(ポジ〜ニュートラル寄り)
  • 「今週のモヤモヤ」枠 — 週1〜不定期(完璧を強要しない、誠実さを保つ)

これで「明るすぎず、暗すぎず、リアル」が両立する。Gottman の 5:1 や Baumeister の "Bad is stronger than good" の知見と整合。

返信原則(既存4原則 + 1)

OC handbook の4原則に加えて:ネガティブ投稿には、事実を映してから、空間を残す。無理にポジティブを足さない。次のポジ投稿の余地を残しておくのも、ポジ:ネガ比のうち。

核心の一語:ノイズを減らす

THE CORE WORD — 追記 2026.07.12
ブランドの中心は「早起き」ではなく、「ノイズを減らして、自分に戻る」。早起きは、その入り口のひとつ。

3本柱の読み直し

柱 01 — 環境をつくる
= 意志で戦うノイズを減らす。スマホを遠くに置くのは、我慢の訓練ではなく、戦わずに済む設計。
柱 02 — 興奮をアウトプットする
= 頭の中のノイズを外に出す。書く・話す・出し切る。
柱 03 — 行動で気分を変える
= 考え続けるノイズを止める。動くことで、頭の回転を一度切る。
発見 3つの柱は、別々のことを言っていたのではない。3つとも「ノイズを減らす」を言っていた。

朝の不安は、時間帯の問題

朝はコルチゾールが上がる時間帯で、生理的に不安を感じやすい。将来不安が朝いちばん大きくなるのは、意志の弱さではなく時間帯の問題。この前提を共有するだけで、自分を責める材料がひとつ減る。

「小さく始める」だけでは足りない理由

水を一杯飲むことは行動のハードルを下げるが、将来不安には効かない。「こんなことでいいのか」と焦って続かなくなる。必要なのは、もっと大きな行動ではなく、その行動が何につながるかを自分の言葉で持つこと(= 方針)。方針がないまま手順だけを実行しても続かない。

注意 「もっと頑張る」はノイズを増やす。習慣を積み上げて完璧を目指す形は、静けさに向かうどころか、新しいノイズの追加になる。

比較の相手は他人ではない

見るのは「自分がどれだけ出来たか」。記録を取るのも、誰かと比べるためではなく、自分の変化を自分で見られるようにするため。
