OC運営ハンドブック

最終更新 2026.05.22

LINEオープンチャット「早起き習慣🌅ゆるく続ける朝活部屋」の運営返信ルール集。

同じ失敗を繰り返さないため に、ブランド哲学・原則・状況別パターン・過去の失敗を1ページに集約。

◇

大原則

PRINCIPLE 1
相手の言葉を、相手の言葉のまま返す
PRINCIPLE 2
事実を述べる。評価しない。解釈を捏造しない。
PRINCIPLE 3
立ち位置は「少し先を歩いてる仲間」
教師でも専門家でもない
PRINCIPLE 4
押し付けない。
「ゆるく続ける」哲学を体現する。
✓

返信ルール(◯と✕)

◯ やること
  • 認める・共感する
  • 「続いてますね」と事実を述べる
  • 具体的な時間を出す(「6:40!」)
  • 相手の使った言葉をそのまま返す
  • 結果ではなく「向かおうとする姿勢」を認める
  • 悩みには共感だけ
  • 目標は本人の言葉のまま認める
  • シンプルに
✕ やらないこと
  • 評価する(「すごい」「えらい」)
  • 「気にしないでくださいね」(上から目線)
  • 聞かれてないアドバイス
  • 説教・長い説明
  • 「報告」という堅い言葉
  • 他人と比較
  • 勝手な解釈・目標を捏造
  • 「教えてくれてありがとう」を時間共有に使う
▣

状況別 返信パターン

普通の報告(「おはよう」のみ)
おはようございます☀️ [名前]さん、続いてますね👏 良い一日を🌅
時間を共有してきた
えびちゃんさん、6:40! → 時間を見たことを示すだけ。 解釈・比較・「ありがとう」は不要。
目標・内省・自己開示を共有してきた
えびちゃんさん、教えてくれてありがとうございます😊 → 深い共有にだけ「ありがとう」OK。 事実報告には不要。
目標を表明していた人の進捗が見えた時
えびちゃんさん、6:40! 修正、進んでますね👏 → 本人が使った言葉(例:「修正」)を そのまま使う。 勝手な目標・比較を捏造しない。
悩み共有(「眠れない」など)
[名前]さん、眠れない夜は辛いですよね。 ノートにも書いてあるので、 良かったら見てみてください🌱 → 共感だけ + ノートに案内 (アドバイスはしない)
忘れて戻ってきた人
[名前]さん、おはようございます😊 忘れても戻ってくるのが大事です🌱 → 不在を責めない。 戻ってきたこと自体を認める。
新規参加(初回)
[名前]さん、参加ありがとうございます！ ここはゆるく「おはよう」を共有する場所です🌱 → 1回だけ。継続的に追わない。
久しぶりに登場した人
[名前]さん、久しぶりですね😊 おはようございます☀️ → 不在期間に触れない。 理由も聞かない。
運営側が寝坊した日
おはようございます☀️ 今日は7時に起きました。 日曜はゆっくりめです😊 → 正直に共有 = 信頼。 「リーダーも完璧じゃない」を体現。
返信が遅れた(数時間以上)
→ 18時以降に「おはよう」は不自然。 明日の朝に自然に返す方が良い。 「遅れてすみません」を翌朝1回だけ添える。
⚖

やりすぎ防止チェック

毎回送る前にセルフチェック。1つでも当てはまったら削る。

  • 毎回コツを入れてないか?(週1-2回でOK)
  • 褒めすぎてないか?(自然に認めるだけ)
  • 習慣のメリットを語りすぎてないか?
  • 本人が言ってないことを勝手に補完してないか?
  • 「あなたのために」感が出てないか?
  • たまには「おはよう」だけの日にする勇気があるか?
⚠

過去の失敗パターン

実際にやってしまった失敗の記録。同じ過ちを繰り返さないために明記。

失敗 1:過去形で「おはようございました」
竹田さん、昨日もおはようございました😊
竹田さん、昨日も続いてましたね👏
「おはようございました」(過去形)は日本語として不自然。
失敗 2:文脈ない「ありがとう」
竹田さん、昨日もありがとうございました😊
竹田さん、昨日も続いてましたね👏
「おはよう」を共有しただけの相手に「ありがとう」は変。何かしてもらった時の言葉。
失敗 3:全員まとめて「続いてますね」
はるさん、りんごさん、えびちゃんさん、竹田さん、続いてますね👏
[個別に時間や文脈を入れて認める]
省略しすぎで「ちゃんと見てる感」が出ない。具体的時間や文脈を入れて個別に認める。
失敗 4:勝手な比較を捏造
えびちゃんさん、6:40!
水曜より早くなってますね👏
えびちゃんさん、6:40!
修正、進んでますね👏
「水曜より」は私が勝手に作った比較フレーム。本人の言った言葉(例:「修正」)を使う方が誠実。
失敗 5:目標を捏造
えびちゃんさん、6:40!
目標に近づいてますね👏
えびちゃんさん、6:40!
修正、進んでますね👏
本人は具体的な目標時間を表明していなかった。「目標」という言葉を勝手に作るのは捏造。
失敗 6:意味不明な「進めてる」
えびちゃんさん、6:40!
進めてますね👏
えびちゃんさん、6:40!
修正、進んでますね👏
「何に向かって進めてる?」が不明。動詞には目的語(例:「修正」)が必要。
失敗 7:DMヒアリングを提案
新規メンバーにDMで「どこで知って参加されました?」
Google Form / GA4 / UTM で
自動的にデータが集まる仕組みを設置
ハブを作った目的は「聞きに行かなくて良い状態」。原則:個別判断はしない、仕組みで取る。
⊕

共有の種類と対応の使い分け

時間・状況の共有(例:「6:40に起きました」)
内容を認めるだけ。「6:40!」など事実をそのまま受ける。
「ありがとう」は不要。
目標・悩み・内省・自己開示
相手の使った言葉をそのまま返す + 「教えてくれてありがとう」OK。
悩みには共感だけ・アドバイスしない。
えびちゃんの「最近6時50分と少し遅めなので、これから修正していきます」 → 「修正」という本人の言葉を覚えておく。後日進捗が見えた時に「修正、進んでますね」と返せる。
⟳

返信プロセス(6ステップ)

  1. スクショを撮る — OCの該当画面を保存
  2. 状況を整理 — 誰が・何時に・何を共有したか
  3. ポイント確認 — 継続日数 / 新規 / 久しぶり / 悩み / 目標 / 内省
  4. 返信案作成 — 大原則・ルールに沿って
  5. セルフチェック — yarisugi 防止リストで確認
  6. 投稿タイミング — 平日朝(仕事前) / 土日祝はランダム
